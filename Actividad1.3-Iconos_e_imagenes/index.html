Práctica: iconos y composición de imágenes

1. Barra de iconos

Todos los iconos deben tener el mismo tamaño y estilo, y una alternativa de texto para las personas que no puedan verlos (apartado 8.2 del tema).

2. Regla de los tercios

La rejilla roja marca los "puntos de fuerza" de cada imagen (ver apartado 9 del tema). Sustituye las dos imágenes de ejemplo por otras tuyas y comprueba si el sujeto principal cae cerca de alguno de esos puntos.

3. Ángulos fotográficos

Para cada imagen, indica qué ángulo crees que se ha usado (normal, contrapicado, picado, nadir o cenital) y en qué tipo de página web lo usarías.

4. Reflexión final

El uso de fuentes de iconos es mucho mejor que usar imágenes sueltas poner iconos en la web para porque las fuentes web aparte de dar más opciones de personalización, hacer que estos iconos sean responsive de manera más sencilla, reducir el uso de texto innecesario y el tiempo para entender que hace el icono, también ayuda a que la carga de la web sea más rápida. Los iconos que usemos deben ser representativos, significaticos y funcionales.
